# 実験3: 気象リーグ（気象庁が常設ベンチ）

**問い**: 個人＋AIは、国家予算の予報にどの条件で勝てるのか / 負けるのか。

- **予測対象**: 翌日の東京（アメダス44132）の日最高気温
- **提出**: 毎日18:00 JST（気象庁の17:00発表後）。`picks/YYYY-MM-DD.json` に凍結＝コミット履歴が公証
- **採点**: 翌々日にアメダス実況で。絶対誤差（℃）。oracle=誤差0
- **ベンチ**: `jma`（気象庁そのまま＝強敵）／`persistence`（今日の実績＝明日の予測＝脳死）
- **機体**: `openmeteo`（別モデル）／`blend`（平均）／`debias`（直近30日の系統誤差を差し引く）
- **判定日**: n≥30日
- **見る場所**: [weather_forward.md](reports/weather_forward.md)

**このリーグの特異点**: 脳死ベンチと同時に**世界最強クラスのベンチ**が常設されている。負けても「どの条件で負けるか」が分かり、それは電力リーグの入力（予報の信頼度）に直結する。
