# 実験8: 出力制御リーグ（九電の見通しを先回りする）

**問い**: 再エネの出力制御が「明日あるか」を、系統運用者より先に当てられるか。

**設計上の判断**: 制御の**実績量は時系列で公表されていない**（2026-08-23に一次確認）。公表されるのは毎日17:00の見通しだけ。そこで予測対象を実績量ではなく**九電が17:00に出す見通しそのもの**にした——ラベルが毎日必ず publish され、曖昧さがなく、oracleが自明。

- **提出**: 毎日07:00 JST（発表より10時間早い）→ `picks/` に凍結＝コミット履歴が公証
- **採点**: 同日17:10に九電の発表と突き合わせ
- **脳死ベンチ**: `always_none`（常になし）／`persistence`（今日と同じ）
- **判定日**: n≥60日。ただし**夏は制御がほぼ出ないので本番は春（4-5月）と秋（10-11月）**——それまでは収集期間
- **礼儀**: 1日2回・User-Agent明示・robots順守
