# exp12 図面のCAD化（試作・2026-10-04）

目的: ココナラで「間取り図のCAD化」を売るときの、自分の仕組み（受け取り→線の抽出→DXF→機械検品→人の確認→納品）の試作。
既存のAI変換サービスは規約上、代行への利用に許可が要り、APIも無いため、線の抽出を自分で持つ。

| ファイル | 役割 |
|---|---|
| `make_sample.py` | 権利の問題を避けるため、架空の間取り図を描く（sample/plan.png） |
| `trace.py` | 画像→壁の線分→DXF（ezdxf）。元図に重ねた確認用PNGも出す |
| `check.py` | DXFを機械で検品。縮尺の妥当性・短い線・端が浮いている点（開口か途切れ）を列挙し、人が見る所を絞る |

初回（架空の図面）: 線分11本、外形10.0×7.0m、端が浮いている点6個＝窓1・戸2・玄関1に一致。
次: 実物に近い図面（文字が線に重なる・線が薄い）で精度を見る。文字はOCRで位置を拾い、人が入れる。
