# exp01: JEPXスポット価格

電力の卸市場（前日スポット、30分×48コマ）の価格を毎日取って眺める実験。

## 使い方

```bash
python3 fetch.py 2025 2026   # 年度単位でCSV取得（UTF-8変換して data/ に保存）
python3 plot.py              # output/ に観察プロット2枚
python3 sim.py               # 仮想蓄電池のバックテスト（インサンプル、戦略開発用）
python3 forward.py           # 【日課】フォワード運用: データ更新→台帳→明日のpicks→レポート
```

フォワード運用: 戦略凍結2026-08-12、開始2026-08-14受渡分。ステートレス台帳方式
（毎回凍結ルールで全再計算、公開成績は再実行で検証可能）。出場機体は
clock / weekshape / haruki_tenki / haruki_hybrid（平常時weekshape・日射平年乖離が
閾値超えの日だけtenki）。レポートは `output/forward_report.md`。

## データの読み方メモ

- ファイルは年度（4月始まり）単位。**翌日分の価格が前日の夕方には確定して載る**（前日市場なので）
- 列: 年月日, 時刻コード(1-48), 売り/買い入札量, 約定総量, システムプライス, エリアプライス×各エリア
- コマ1 = 00:00-00:30
- 見どころ: 昼の太陽光による価格低下（0.01円/kWhが出る日も）と夕方の跳ね上がり、日内スプレッド、季節・寒波での高騰
