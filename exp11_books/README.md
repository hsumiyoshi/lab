# 実験11: 書籍ランキングリーグ（トップ10の残存数）

**問い**: ヒットはどれくらい持続するのか。来週も残る冊数を、脳死ベンチより当てられるか。

**なぜこの素材か**: 既存9リーグが価格・物理・制度に偏り、**文化消費（人が何を選ぶか）**の象限が空だった。週1回の取得で済む軽さも利点。

**なぜ「1位当て」でなく「残存数」か**: 1位当ては運の比重が大きい。残存数（0〜10）なら①正解が機械的に確定 ②脳死ベンチ（全部残る=10）が明確 ③oracleが自明——リーグ規約の3条件を満たす。しかも**ヒットの持続性という現象そのもの**が測れる。

- **提出**: 毎週木曜07:00 JST → `picks/` に凍結
- **採点**: 翌週の取得時
- **脳死ベンチ**: `all_stay`（10冊）／`persistence`（前回の実績）／`mean`（過去平均）
- **判定日**: n≥12週
- **見る場所**: [books_forward.md](reports/books_forward.md)
