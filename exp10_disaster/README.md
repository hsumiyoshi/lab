# 実験10: 全球災害リーグ（GDACS）

**問い**: 全球で明日いくつ災害イベントが立ち上がるかを、脳死ベンチより当てられるか。

**このリーグの資産性**: GDACSのRSSは**巻き取り式**で古いイベントが落ちる。毎日取り込んで自分で履歴を作らない限り**後から遡れない**——「その時に測っていた人しか持てない」型のデータ（#20の類型③）。継続そのものが堀になる。

- **予測対象**: 翌日(UTC)に新規登録される山火事(WF)イベント数（全球・最頻カテゴリ）
- **提出**: 毎日07:00 JST → `picks/` に凍結
- **採点**: 翌々日（UTCの日が確定してから）
- **脳死ベンチ**: `persistence`（今日と同じ）／`ma7`（直近7日平均）
- **判定日**: n≥30日
- **今後**: 履歴が貯まったら気象データ（高温乾燥域）と結合した機体を投入。地震(EQ)・熱帯低気圧(TC)・洪水(FL)も同じ台帳で扱える
- **見る場所**: [disaster_forward.md](reports/disaster_forward.md)

## 第2系統: FIRMS（衛星の熱異常検知）

GDACSが「人が定義したイベント」を数えるのに対し、FIRMSは**衛星が観測した熱異常のピクセル数**という物理量。同じ山火事を①人の集計 ②機械の観測 の2系統で持ち、**両者のズレ自体を観察対象にする**（イベント化されない火災／大きく報じられる小火災）。

- 有効化: リポジトリのSecretsに `FIRMS_MAP_KEY` を登録するだけ（[無料発行](https://firms.modaps.eosdis.nasa.gov/api/map_key/)）
- 鍵が無い間は何もせず正常終了する（CIは落ちない）
