公証の仕組み

  1. picksは市場価格の公表前にコミットされる——後出しは不可能
  2. gitのコミット履歴が、改竄不能なタイムスタンプ＝公証になる
  3. 負けた記録も削除しない。全履歴が誰でも検証できる

縦軸は上限の何%を取れたか。灰色の帯は予測を一切しなくても届く領域——clockは毎日同じ時間に売買するだけだが、電力価格の日内周期のせいで上限の8割強に達する。つまり勝負はこの帯の上、残り2割弱の奪い合いで起きている。90%台という数字を実力と読まないための線。立ち上がりは分母が小さく比率が暴れるため、各機体4日目から描く
