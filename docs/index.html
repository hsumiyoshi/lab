何の勝負？

仮想蓄電池のデイリー売買ゲーム

毎日、翌日48コマ（30分刻み）の価格を予測。安い4コマで充電（買）、高い4コマで放電（売）。差額が損益になり、答え合わせは翌日13:30。

clock
毎日同じ時間に売買する脳死ベンチマーク
weekshape
曜日ごとの価格の形を真似る
tenki
天気予報から価格の形を予測する
hybrid
普段はweekshape、天気が荒れる日だけtenki
tenki_v2
同季節×類似天気の過去日から形を引く（類似日アンサンブル・8/16参戦）
tenki_v3
v2の類似日を20日に拡大（分割検証で選抜・8/16参戦）
tenki_v4
気温を快適帯距離|t−21℃|に折った類似日。分割検証では選抜漏れ→参考出場（却下判定の正しさをフォワードが審判する）
oracle
答えを見て動いた場合の理論上限（参照値。順位には入らない）
